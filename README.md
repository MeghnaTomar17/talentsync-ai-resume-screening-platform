# TalentSync AI

AI-powered Resume Screening & Skill Gap Analysis Platform using NLP, semantic embeddings, and ATS-style ranking workflows.

## Features
- Resume preprocessing pipeline
- Skill extraction & normalization
- TF-IDF similarity matching
- Semantic embedding matching
- Skill-gap analysis
- ATS scoring system
- Resume ranking engine

## Tech Stack
- Python
- Pandas
- Scikit-learn
- Sentence Transformers
- NLP
- Matplotlib
- Seaborn
